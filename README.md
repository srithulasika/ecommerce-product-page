
# E-commerce Product Page

A responsive e-commerce product listing page built using HTML and CSS.

## Features

- Responsive navigation bar
- Product grid using CSS Grid auto-fit and minmax()
- Product cards with images, names and prices
- Filters sidebar with category and price options
- Filters sidebar moves below the products on mobile
- Responsive desktop, tablet and mobile layouts
- Sticky footer at the bottom of the page

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Project Structure

```text
ecommerce-product-page/
├── index.html
├── README.md
└── css/
    └── style.css
```

## Responsive Design

- Desktop: Product grid with filters sidebar on the right.
- Tablet: Smaller product cards with the sidebar beside the products.
- Mobile: Product grid appears first and filters move below it.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
